# Native Destiny reference

The live server remains JavaScript. This lane records the boundary to the
pinned CCP Carbon source and may hold fixtures or optional oracle adapters, but
live gameplay must not depend on a native build without a separate reviewed
change.

Ports must be independently implemented from pinned, licensed Carbon source
and executable eve.js/client evidence. General ship/static collision mechanics
stay excluded. Native missile evolution, interception, impact, lifetime, and
the targeted `MISSILE/FREE|MASSIVE` presentation remain required.
